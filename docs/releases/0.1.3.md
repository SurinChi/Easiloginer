# EasiLoginer 0.1.3

## 本次重点

- **设置页改版**：原「配置」页更名为「设置」，设置项按功能分为「登录」「提醒与遮罩」「应用与外观」三栏，用顶部导航切换；「保存」仍然一次写回全部设置。分类导航也补了无障碍名称。
- **快捷登录横排**：档案按钮由纵向列表改为横向等宽卡片，按行排列并自动换行；左侧导航图标统一为 Fluent 图标，修复「快捷登录」闪电图标明显偏大的问题。
- **应用内公告**：启动时最多每 6 小时检查一次公告（失败静默、不阻塞启动），「关于」页可手动查看。发布新版本或维护通知只需提交 `announcements/announcements.json`，不需要重新发版；勾选「不再提示」后按公告 ID 持久化。

## 修复

- 「同一时刻只允许一个登录任务」实际没有生效：互斥状态挂在每次新建的实例上，跨页面同时点登录会启动两条管线、互相杀进程。现在由进程级闸门拦截第二个请求。
- 登录准备阶段（杀进程并等待退出、启动希沃、枚举设备）会阻塞主界面，已移到线程池执行。
- 配置读取被临时占用（编辑器、杀软、另一实例正在写）时，旧逻辑会当成文件损坏并用默认值覆盖；现在重试后只以默认值运行、不写盘，只有真正解析失败才备份并重置。
- 配置里嵌套段被写成 `null` 时启动会空引用崩溃；现已用默认值补齐。
- 启用主密码后，保存账号/密码会先校验主密码，校验触发的列表重建会把刚改的内容换成磁盘旧值却提示「已保存」；已修复，并保证「运行登录」同样先过主密码校验。
- 运行前确认弹窗被 Alt+F4 或随主窗口关闭时会被当成「立即执行」；现在按取消处理。
- 主实例接收转发命令时会把 `-p/--password` 明文写进日志；现在账号与密码一律打码。
- IPC 回调抛异常会永久终止单实例转发；同名管道被占用时会无延迟空转占满一个核心。均已修复。
- `patch --on/--off` 此前只是占位实现，令牌投递因此无法启用；现在可用（退出码 20 成功、21 失败、22 未找到希沃）。DLL 修补不再在缺少目标文件时报成功，撤销也会先恢复程序集再删管道桥，避免留下无法启动的希沃。
- 更新下载在取消/超时后残留 `.part` 文件；Dev 通道只取一条发布、会漏掉更高版本；发布方未提供 SHA-256 时界面不再声称「已通过校验」。

## 下载

| 文件 | 适用 |
| --- | --- |
| `EasiLoginer-Setup-0.1.3.exe` | 推荐；双击安装，默认装到 `%LOCALAPPDATA%\Programs\EasiLoginer`，无需管理员权限 |

## 升级说明

- 覆盖安装只替换程序文件，`data\` 里的配置与档案会保留；卸载才会删除整个安装目录。
- 从 0.1.2 及更早版本升级不需要迁移数据，配置文件与档案格式保持双向兼容。

## 已知问题

- 发布包未做代码签名：SmartScreen 提示时点「更多信息 → 仍要运行」；开启 Smart App Control 的机器可能直接拦截（`0x800711C7`）。
- 令牌投递需要先执行 `EasiLoginer.exe patch --on`（需要写入希沃安装目录的权限）；撤销用 `patch --off`。
- 图像识别仅支持 1920×1080@100% 与 3840×2160@200% 的显示环境。

# EasiLoginer 0.2.0

> 版本号：`0.2.0`。这是 0.2 系列的第一个稳定版，建议所有 0.1.x 用户升级。

## 本次重点

- **完整版用户协议**：首次设置向导不再展示摘要，而是完整协议（许可、数据与隐私、希沃白板修补风险、免责声明、责任限制、协议变更等）；必须滚动到正文末尾才能勾选「我同意」，勾选前「下一步」与「跳过向导」均不可用。应用内「关于 → 用户协议」可随时查看同一份文本。
- **安装流程重做**：目标目录已存在时不再弹 Inno 的「文件夹已存在」警告，改为明确的「保留数据安装」确认：只替换程序文件，`data\` 中的配置与档案保留；目录选择页与就绪页也会说明这一点。
- **亚克力效果**：窗口背景采用应用内模糊，模糊强度（0–60）与玻璃不透明度（20–100%）都可以在设置页调整；比系统亚克力更可控，Windows 10 / 11 表现一致。
- **背景系统**：支持跟随桌面壁纸、本地图片、纯色和渐变四种背景来源；壁纸 / 图片模式下自动叠加可调透明度的玻璃层，保证文字可读性。
- **公告独立页面**：公告从「关于」页抽出，导航入口放在「关于」下方；支持手动刷新、查看详情和空状态提示，启动时的公告提醒仍然保留。
- **关于页与 README 换新**：新增一张展示应用界面的大横幅；作者信息前置，加入头像、官网与 GitHub 链接；关于页只保留四个核心亮点，删去冗长说明。
- **档案安全收紧**：启用主密码后，密码不以明文长期存在内存/界面；隐藏“显示密码”；修改账号或密码可用主密码或该档案原密码验证；更换主密码需要旧主密码。
- **登录可中止**：状态浮窗新增「立即终止」按钮，点一下即可取消当前登录流程，不改动任何设置。
- **设置迁移到注册表**：全部设置写入 `HKCU\Software\EasiLoginer\Settings`，每个设置项一个注册表值；旧 `config.json` 与旧版单值注册表配置都会自动迁移。
- **安装器品牌侧边栏**：安装向导左侧换成 EasiLoginer 专属竖向视觉，右上角同步使用应用图标。
- **应用内静默更新**：更新页下载完成后可「静默安装并重启」，安装器结束旧进程、完成覆盖安装后自动启动新版本。
- **长期公告**：新增「给所有使用者的一封信」，长期展示开发缘起、致谢与祝愿。

## 本次测试重点

- 公告页：从「关于」下方进入，能读取本地/远程公告，刷新、详情链接和空列表都正常。
- 关于页：大横幅、头像、官网、GitHub、问题反馈、用户协议链接在 100% / 150% / 200% 缩放下都能正常显示和滚动。
- README 横幅与作者信息在 GitHub / Gitee 的 Markdown 渲染中正常显示。
- 覆盖安装到已有目录，确认提示「保留数据安装」且 `data\` 中的配置与档案未丢失。
- 首次向导协议：不滚动到底部时「我同意」「下一步」「跳过向导」均不可用；滚动后可勾选并继续。
- 四种背景来源（桌面壁纸 / 本地图片 / 纯色 / 渐变）与模糊强度 0、30、60 的显示效果和拖动帧率。
- 不同显示缩放（100% / 150% / 200%）以及 Windows 10 真机（当前开发环境为 Windows 11）。
- 从 0.1.3 升级后，确认设置项、档案和登录方式没有被重置。
- 加密档案：改账号/密码后切页再回来，保存仍要求验证；密码框不再有显示按钮。
- 状态浮窗「立即终止」能中止登录；设置页保存后写入注册表，重启后仍生效。
- 安装向导侧边栏显示 EasiLoginer 竖向品牌图；应用内静默更新完成后能自动重启新版本。
- 从 Beta 1 升级：旧 `config.json` 自动迁移到 `HKCU\Software\EasiLoginer\Settings`，设置不丢；卸载后注册表设置被清理。
- 设置页修改后出现右下角保存提示；「重置全部」「重置本页」只改编辑器值，点击保存后生效。

## 修复

- 修复切到其他页面后档案密码被清空：WPF 在页面卸载时会清空 `PasswordBox`，之前这个空值被写回视图模型，导致返回档案页后密码看起来为空、点「运行登录」提示未填写密码。现在会忽略页面卸载引起的程序性清空，并在返回页面时从模型重新同步密码框。
- 更新下载不再共用 20 秒总超时，改用“连接超时 + 连续 60 秒无数据”判断；慢速但持续有数据的下载不会被误杀。
- 下载源「自动选择」在直连 GitHub 失败后依次回退到 ghfast / ghproxy 镜像。
- 下载失败时显示具体原因（连接超时 / 下载停滞 / 校验失败 / 所有下载源均不可用），不再只显示 “The request was canceled”。
- 修复「添加」后未填账号的空白草稿阻塞已有档案保存：保存时会跳过并提示该草稿，不再整份保存失败。
- 校验失败时点名具体档案，例如「档案「新档案」的账号不能为空」。
- 修复加密档案修改账号/密码后切换页面再回来、点保存可绕过主密码的漏洞：敏感字段基线改存仓储，跨页面保留。
- 启用主密码后不再把已保存密码解密回档案对象；登录时才临时解密，保存/离开页面时清掉明文草稿。

## 改进

- 设置页新增「外观与背景」分组：启用亚克力、模糊强度、玻璃不透明度、背景来源、背景颜色、渐变结束颜色、背景图片（带「浏览…」）。
- 背景图片支持 png / jpg / bmp / webp；文件不存在或格式非法时自动回退到桌面壁纸 / 主题色，不会出现空白窗口。
- 主题切换时同步重算玻璃层底色，避免深色主题配浅色底。
- 首次向导的协议页改为「正文、提示、勾选框同屏」布局，正文单独滚动，不会因为外层滚动而看不到「我同意」。
- 未同意协议直接关闭首启向导时，程序会退出而不是进入主界面；下次启动会再次要求阅读协议。
- 导航栏宽度收窄到 240，关于页横幅按 1600×560 原始比例自适应内容宽度，不再被左右裁切。
- 安装程序启动时检测旧版本：弹窗询问是否结束正在运行的 EasiLoginer，确认后结束进程并继续安装；静默安装直接结束旧进程。
- 公告页副标题精简，只保留用途说明。
- 统一四种登录方式名称，以设置页为准：固定位置、图像识别、自动定位、令牌投递；首次向导、关于页、用户协议和 README 不再混用「UI Automation」。
- 设置存储从 `config.json` 改为当前用户注册表，按设置项拆分为独立注册表值；旧配置自动迁移，卸载时清理设置。
- 设置页增加「重置全部」「重置本页」与右下角未保存提示；副标题改为“更改后请保存设置项，未保存的改动将不生效。”
- 「创建桌面快捷方式」恢复为安装时默认勾选。
- 用户协议更新到 1.1，补充注册表存储与密码内存策略。
- 版本号统一由 `Directory.Build.props` 提供，安装包与发布材料自动跟随。

## 升级说明

- 覆盖安装只替换程序文件，`data\` 里的配置与档案会保留；安装向导会明确提示「保留数据安装」。
- 从 0.1.x 升级不需要迁移数据；`config.json` 中新增的 `Appearance` 段会自动以默认值补齐。
- 默认外观为「跟随桌面壁纸 + 亚克力」；如果桌面壁纸不可用，会自动回退到主题纯色背景。

## 已知问题

- 发布包未做代码签名：SmartScreen 提示时点「更多信息 → 仍要运行」；开启 Smart App Control 的机器可能直接拦截（`0x800711C7`）。
- 令牌投递需要先执行 `EasiLoginer.exe patch --on`（需要写入希沃安装目录的权限）；撤销用 `patch --off`。
- 图像识别仅支持 1920×1080@100% 与 3840×2160@200% 的显示环境。
- 极高模糊强度（接近 60）在低端集成显卡上可能略影响窗口拖动帧率；可降低到 20–30。

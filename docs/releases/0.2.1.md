# EasiLoginer 0.2.1

> 版本号：`0.2.1`。这是 0.2.0 的修复版，建议所有 0.2.0 用户升级。

## 修复

- **启用主密码不再要求验证档案密码**：此前启用加密时会先要求输入当前档案原密码，这与“设置主密码”的语义不符；现在只设置并确认主密码。
- **修改账号/密码的验证弹窗改为双页**：顶部可切换「通过主密码验证」与「通过档案原密码验证」。
  - 档案没有已保存密码时，「档案原密码」页禁用。
  - 档案处于锁定状态时也只能先用主密码解锁，避免无法解密的原密码页误导用户。
- **档案状态文案精简**：未加密时显示「档案未加密」，删去括号中的「明文保存」。
- **解锁入口不再常驻**：本机 DPAPI 缓存可自动解锁时隐藏「解锁」按钮；只有缓存失效、需要手动输入主密码时才显示。

## 说明

- 「解锁」只用于恢复当前会话的档案解密密钥，不是希沃账号登录，也不会修改主密码。
- 主密码使用 Argon2id 派生密钥、Fernet 加密档案中的账号密码；本机缓存使用当前 Windows 用户的 DPAPI。
